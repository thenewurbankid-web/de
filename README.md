# Deutsch – Null bis B1

A personal German course for life in Berlin, from zero to B1, as one static page.

- Day-by-day plan with daily goals, streak and a daily speaking mission in Berlin
- Survival track first (shops and street in about 3–4 weeks), then A1, A2, B1
- Spaced-repetition flashcards with German audio (browser speech)
- Quizzes, dictation, shadowing with speech recognition, verb trainer
- Skill tracking (vocabulary, grammar, verbs, reading, listening, writing, speaking) that adapts the plan to weak spots
- Mock exams for A1, A2 and B1 in the Goethe/telc format (original texts), with readiness bars and estimated dates
- Optional tutor that runs in the browser with WebLLM (needs WebGPU)
- The app speaks German; hover or tap any German text for English

Progress is saved in the browser's localStorage (Settings → export to move it).

Edit content in `src/`, then run `sh build.sh` to rebuild `index.html`.
